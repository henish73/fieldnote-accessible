    Keyboard shortcuts

    Single-key shortcuts work when you are not typing in the search box. Tab, Shift+Tab, Enter, Space and the arrow keys always work.

    KeyWhat it does
    /Go to the search box
    rGo to the first result
    fGo to the type and filter choices
    uUndo the last type or filter change
    ?Open this list
    Alt + ←Browser Back: return to the previous view
